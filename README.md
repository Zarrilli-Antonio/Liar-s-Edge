# Question Library Builder

Static site pronta per GitHub Pages per creare file JSON multilingua per Liar's Edge.

## Struttura
- `index.html`
- `styles.css`
- `app.js`

## Funzionalità
- Aggiunta e rimozione di domande
- Traduzioni per `it`, `en`, `fr`, `es`
- Anteprima JSON in tempo reale
- Download del file `question-library.json`
- Copia negli appunti

## Formato JSON generato
Ogni domanda contiene `translations` con le traduzioni della stessa domanda.

## Uso su GitHub Pages
Carica la cartella su un branch dedicato o pubblicala tramite GitHub Pages e apri `index.html` come root del sito.
